## Why vocabulary batches and a cache bump were not made

The requested extraction depends on the complete target prose. Without that file, source tokens, lemmas, candidate counts, duplicate decisions, family classifications, and Persian translations cannot be derived honestly. Creating batches from project documentation or unrelated text would violate the request's source-selection and linguistic-quality rules. Because no new dictionary entries were accepted and `data.json` remained byte-for-byte unchanged, no Service Worker cache-version bump was made.

## Required input to complete v1.5.1

Supply the intended English prose as a `.txt` file or include it in the project archive. Once available, run the full source coverage analysis, compare candidates against the current database and all authoring exclusions, create unique supplemental batch files, rebuild `data.json`, update exclusion lists only for entries accepted by the final build, increment the Service Worker cache version, and rerun validation.
